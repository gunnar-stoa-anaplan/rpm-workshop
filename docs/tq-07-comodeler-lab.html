CoModeler Lab A — Generate a Line Item Dictionary

Use CoModeler to generate a complete line item dictionary for the SYS Territory Quota module — the core quota calculation module in T&Q.

  1. Open the T&Q V2 template app in your partner workspace.
  2. Navigate to the SYS Territory Quota module (use the model map or search).
  3. Open CoModeler for this module.
  4. Prompt CoModeler: "Generate a line item dictionary for this module. For each line item include: name, formula summary, data type, and purpose."
  5. Review the output. Identify which line items calculate: (a) the base target, (b) the assignment percentage adjustment, and (c) the ramp factor adjustment.
  6. Export or copy the dictionary — you'll use it as a reference during the extension exercise.
💡 What to Look For

The quota calculation follows this pattern: Base Target × Assignment % × Ramp Factor = Rep Quota. Find the line items that represent each of these three inputs and confirm you understand how they connect.

Done when you can answer Which line item in SYS Territory Quota holds the final calculated quota value for a rep? What are its inputs?

CoModeler Lab B — Explain the Quota Calculation Logic

Use CoModeler to understand exactly how quota is calculated for a rep who covers multiple territories with different assignment percentages.

  1. With the T&Q template app open, launch CoModeler.
  2. Ask: "How does the quota calculation work when a single rep is assigned to multiple territories at different assignment percentages? Walk me through the formula logic step by step."
  3. Read the explanation. Then ask a follow-up: "Which module consolidates the quota across all territories for a single rep, and what is the output used for downstream systems like ICM?"
  4. Note the module name that consolidates multi-territory quota (hint: it's the one you'd export to CRM/ICM).
  5. Ask one more: "If a rep has a ramp profile that starts at 0% in month 1 and reaches 100% in month 4, how does the app calculate their prorated annual quota?"
Done when you can answer What is the name of the module that holds the consolidated quota for a rep across all their territory assignments? Why does this matter for ICM integration?
